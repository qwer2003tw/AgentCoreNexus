### 3. 🔴 重命名功能（關鍵測試！20 分鐘）

**重要性**：⭐⭐⭐ 這是 E2E 測試失敗的核心功能

#### 3.1 執行重命名
- [ ] 選擇第一個對話
- [ ] 右鍵點擊對話（或找重命名按鈕）
- [ ] **如果出現右鍵選單**：選擇「重命名對話」
- [ ] **如果沒有右鍵選單**：找其他重命名入口
- [ ] **驗證**：彈出重命名對話框

#### 3.2 輸入新標題
- [ ] 在對話框輸入：「真實環境測試 - 重命名驗證」
- [ ] 點擊「確定」按鈕
- [ ] **立即觀察**：對話框是否關閉

#### 3.3 驗證更新（關鍵！）
- [ ] **觀察側邊欄**：標題是否立即更新？
  - [ ] ✅ 是：標題顯示「真實環境測試 - 重命名驗證」
  - [ ] ❌ 否：標題仍是「新對話」
- [ ] 如果標題更新了：
  - [ ] 等待 2-3 秒觀察是否穩定
  - [ ] 刷新頁面（Ctrl+F5）
  - [ ] **驗證**：標題持久化（刷新後仍是新標題）

#### 3.4 開發者工具診斷（必須）
- [ ] 打開 DevTools（F12）
- [ ] 切換到「Network」tab
- [ ] 清除日誌
- [ ] 重複步驟 3.1-3.2（再次重命名）
- [ ] **查看 Network**：
  - [ ] 是否有 PUT 請求？
  - [ ] URL 是什麼？（應該是 /conversations/[id]）
  - [ ] 狀態碼？（應該是 200）
  - [ ] Request Payload 是什麼？
  - [ ] Response 是什麼？
- [ ] 切換到「Console」tab
- [ ] **查看錯誤**：是否有紅色錯誤訊息？

#### 3.5 記錄詳細結果

**如果成功**：
```
✅ 重命名功能正常
- 標題立即更新：是
- 標題持久化：是
- Network 請求：PUT /conversations/xxx (200 OK)
- Console 錯誤：無
```

**如果失敗**：
```
❌ 重命名功能失敗
- 標題是否更新：否
- Network 請求：
  * 有 PUT 請求嗎？_____ 
  * URL: _____
  * 狀態碼: _____
  * Request: _____
  * Response: _____
- Console 錯誤：_____
- 截圖：[附上截圖]
```
