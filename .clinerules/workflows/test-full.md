# 完整測試流程

執行專案的完整測試套件，包含代碼質量檢查、單元測試、E2E 測試和覆蓋率驗證。

## 使用方式

在 Cline 中輸入：`/test-full.md`

---

## 執行步驟

### 1. 代碼質量檢查 ⭐

首先執行 Ruff 檢查並自動修復：

```bash
ruff check . --fix && ruff format . && ruff check .
```

**驗證要求**：
- 必須顯示 `Found 0 errors` 或 `All checks passed!`
- 如果有錯誤，報告詳細錯誤並停止流程
- 不允許有任何 linting 錯誤

---

### 2. 執行完整測試套件 ⭐

```bash
make test
```

**監控測試結果**：
- 如果所有測試通過（XX passed, 0 failed），繼續下一步
- 如果有失敗的測試：
  - 顯示失敗的測試名稱
  - 詢問用戶是否要查看詳細錯誤
  - 提供修復建議
  - 停止流程，不繼續後續步驟

---

### 3. 覆蓋率檢查 ⭐

生成並檢查測試覆蓋率：

```bash
make coverage-report
```

**驗證覆蓋率**：
- 檢查整體覆蓋率是否 > 70%
- 如果可用，檢查新代碼覆蓋率是否 ≥ 80%
- 如果覆蓋率不足，指出未覆蓋的代碼區域

---

### 4. 提供建議 📊

根據測試結果提供下一步建議：

#### ✅ 全部通過的情況
```
🎉 所有檢查通過！

✅ 代碼質量：0 errors
✅ 單元測試：XX passed, 0 failed
✅ E2E 測試：YY passed, 0 failed
✅ 整體覆蓋率：ZZ%
✅ 新代碼覆蓋率：WW%

代碼已準備好提交！

建議的 git 操作：
git add .
git commit -m "feat: [描述變更]"
git push
```

#### ⚠️ 部分失敗的情況
```
⚠️ 發現問題需要修復：

❌ [具體問題描述]

建議：
1. [修復建議 1]
2. [修復建議 2]

修復後請重新執行 /test-full.md 驗證。
```

#### ❌ 覆蓋率不足的情況
```
⚠️ 測試覆蓋率不足：

當前覆蓋率：XX%（目標：> 70%）
新代碼覆蓋率：YY%（要求：≥ 80%）

未覆蓋的代碼：
- [文件名]: [未覆蓋的行數]

建議：
為以下代碼添加測試...

完成後請重新執行測試驗證覆蓋率。
```

---

## 注意事項

### Python 版本
- 必須使用 `python3.11` 執行測試
- 不要使用 `pytest` 直接命令（可能使用錯誤版本）

### 執行時間
- 完整測試通常需要 5-8 分鐘
- 快速測試（使用 `make test-quick`）約 2-3 分鐘

### 失敗處理
- 任何步驟失敗都應停止後續步驟
- 提供清晰的錯誤訊息和修復建議
- 不要忽略或輕視任何失敗

## 相關命令

### 快速測試（跳過 Web E2E）
```bash
make test-quick
```

### 只測試特定組件
```bash
make test-agentcore  # AI 處理器
make test-lambda     # Webhook 接收器
make test-web        # Web 前端
```

### 查看詳細測試輸出
```bash
python3.11 -m pytest tests/ -v --tb=long
```
