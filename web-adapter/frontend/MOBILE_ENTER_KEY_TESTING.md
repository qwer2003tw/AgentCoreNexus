# 📱 移動設備換行功能測試指南

## 🎯 功能概述

**實施日期**: 2026-01-13  
**功能**: 根據設備類型改變 Enter 鍵行為

### 行為說明

#### 📱 移動設備（手機/平板）
- ✅ 按 Enter 鍵 → **換行**
- ✅ 點擊「發送」按鈕 → **發送消息**
- ✅ 發送按鈕更大（最小 48x48dp）
- ✅ 提示文字：「輸入訊息... (Enter 換行，點擊發送)」

#### 💻 桌面設備
- ✅ 按 Enter 鍵 → **發送消息**
- ✅ 按 Shift+Enter → **換行**
- ✅ 提示文字：「輸入訊息... (Enter 發送，Shift+Enter 換行)」

## 🚀 快速驗證命令

### 本地開發環境
```bash
cd web-adapter/frontend
npm run dev
```

### 開啟 DevTools 模擬
1. 開啟 Chrome DevTools（F12）
2. 點擊「Toggle device toolbar」（Ctrl+Shift+M）
3. 選擇設備（iPhone 14, iPad, etc.）
4. 測試 Enter 和按鈕行為
