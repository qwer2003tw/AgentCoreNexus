# E2E 測試素材

本目錄存放 E2E 測試使用的圖片和檔案。

## 📁 需要的測試素材

### 必須準備的檔案

1. **test_noodle.jpg**（圖片）
   - 建議：泡麵產品照片
   - 格式：JPG/PNG
   - 大小：< 5MB
   - 用途：測試圖片分析和 Memory 追問

2. **test_data.csv**（CSV 檔案）
   - 建議：包含 3-5 個欄位的簡單數據
   - 格式：CSV
   - 大小：< 1MB
   - 用途：測試檔案分析和統計

3. **test_report.txt**（文字檔）
   - 建議：簡單的文字報告
   - 格式：TXT
   - 大小：< 1MB
   - 用途：測試文字檔案處理

### 可選的測試檔案

4. **test_product.jpg**（產品圖片）
   - 用途：測試工具組合（圖片識別 + 網路搜尋）

## 📝 創建測試素材

### 方法 1：使用你自己的檔案

將任何圖片/檔案複製到此目錄，並重命名為對應的測試檔案名稱。

### 方法 2：創建簡單的測試檔案

#### 創建測試 CSV

```bash
cat > test_data.csv << 'EOF'
姓名,年齡,城市
張三,25,台北
李四,30,高雄
王五,28,台中
EOF
```

#### 創建測試文字檔

```bash
cat > test_report.txt << 'EOF'
測試報告

第一章：簡介
本報告用於測試檔案分析功能。

第二章：數據
包含基本的統計數據。

第三章：結論
測試功能運作正常。
EOF
```

#### 測試圖片

從網路下載或使用你手機拍攝的照片。

## ⚠️ 注意事項

### Git 管理

- ✅ `README.md` 進入 Git
- ❌ 測試圖片和檔案**不進入 Git**（已在 .gitignore）
- 每個開發者自行準備測試素材

### 檔案大小限制

- 圖片：< 5MB（Bedrock 限制）
- 檔案：< 20MB（Telegram 限制）
- 建議使用小檔案以加快測試速度

### 內容建議

- 使用無敏感資訊的測試數據
- 圖片內容清晰，便於驗證 AI 分析結果
- 檔案結構簡單，便於驗證處理邏輯
